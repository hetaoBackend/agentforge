Weixin Session And Image Support

This change makes Weixin behave like a single current session per peer, with /new to start over, and adds image upload/download support through the Weixin bridge.

What Changed

  • Python channel tracks the current task by account_id:peer_id and resumes it by default when it has a saved agent session.
  • /new clears the current peer session; /new <prompt> immediately creates a fresh task.
  • Inbound Weixin images are downloaded by the bridge and attached to AgentForge tasks as image_paths and prompt_images.
  • Generated local images are collected from task run events or markdown references, hidden from the text body, uploaded by the bridge, and sent back to Weixin.
