Electrobun Migration Summary

READY FOR REVIEW

This run migrates AgentForge's desktop shell from Electron/electron-forge to Electrobun while preserving the Bun backend, React renderer, and loopback REST API.

Current State

The Electron main/preload layer, electron-forge config, and Electron build scripts have been replaced with an Electrobun shell. The renderer keeps its existing desktop bridge surface through a compatibility alias, and the backend still serves the same REST API on 127.0.0.1:9712.

Implemented Changes
  • Added an Electrobun Bun main process that starts runServer(9712).
  • Added Electrobun config, view HTML, and resource packaging for the Weixin bridge and Skill Library vendor assets.
  • Exposed directory selection through Electrobun RPC behind the current renderer facade.
  • Replaced Electron package scripts, dependencies, and documentation with Electrobun equivalents.
  • Added focused tests for native bridge behavior and packaged resource path resolution.
  • Updated a stale architecture comparison report that still described the old Electron/Python packaging model.
  • Aligned Electrobun Bun/view entrypoint filenames with the launcher's index.js contract.
  • Allowed Electrobun views:// renderer origins through backend CORS.
